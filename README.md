# Algoritmos y Programación 1 – Retos de Repaso Semanal

Serie de **7 retos en Python 3** para repasar el contenido de las semanas 1 a 7 del curso en una sesión de alto rendimiento.  
Cada archivo en `retos/` incluye el enunciado completo, las restricciones, una pista técnica y la solución lista para ejecutar.

---

## Índice de Retos

| Semana | Archivo | Título | Temas |
|--------|---------|--------|-------|
| 1 | [`retos/semana_1.py`](retos/semana_1.py) | Conversor de Unidades de Temperatura | Entrada/Salida básica, `float()`, f-strings |
| 2 | [`retos/semana_2.py`](retos/semana_2.py) | Calculadora Robusta con Manejo de Errores | `try/except`, `ValueError`, `ZeroDivisionError` |
| 3 | [`retos/semana_3.py`](retos/semana_3.py) | Estadísticas de una Secuencia Numérica | Tipos primitivos (`int`, `float`, `bool`), aritmética manual |
| 4 | [`retos/semana_4.py`](retos/semana_4.py) | Validador de Contraseña Segura | Operadores lógicos `and`/`or`/`not`, `bool`, `str` |
| 5 | [`retos/semana_5.py`](retos/semana_5.py) | Calculadora de Costo de Envío | Variables, constantes (`MAYÚSCULAS`), expresiones combinadas |
| 6 | [`retos/semana_6.py`](retos/semana_6.py) | Clasificador de Triángulos | Condicionales complejos anidados (`if/elif/else`) |
| 7 | [`retos/semana_7.py`](retos/semana_7.py) | Adivina el Número Secreto | Bucles `for`/`while`, `break`, `continue`, `for/else` |

---

## Estructura del Proyecto

```
retos/
├── semana_1.py   # W1-W2 · Básico
├── semana_2.py   # W1-W2 · Medio
├── semana_3.py   # W3-W4 · Medio
├── semana_4.py   # W3-W4 · Medio-Difícil
├── semana_5.py   # W5    · Medio-Difícil
├── semana_6.py   # W6-W7 · Difícil
└── semana_7.py   # W6-W7 · Difícil
```

## Cómo Ejecutar

```bash
python retos/semana_1.py   # o el número de semana que desees
```

Requiere **Python 3.10+** (no usa `match`, pero sí type hints con `|` en semana 2).
